# Quiet Sudoku

An offline-first Sudoku PWA. Static app files are in `dist/`; there are no runtime dependencies, analytics, accounts, or API calls. Puzzle progress is stored in the browser on each device.

On Android, open the deployed HTTPS link in Chrome, wait for **Ready offline**, then choose **Install on this device** or Chrome's **Add to Home screen → Install**. Open the installed app and test in airplane mode before travelling. Clearing browser/app storage removes offline files and saved progress.

The original app was generated by local DeepSeek V4.1 Flash. Codex repaired and tested it, then added the PWA packaging.
